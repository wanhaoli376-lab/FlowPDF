# FlowPDF

FlowPDF 是面向 Windows 10/11 的本地双模式 PDF 编辑器。界面默认使用简体中文；文件不上传、
不登录、不含遥测和广告。`0.1.0a1` 同时保留固定坐标的“版面编辑模式”，并提供面向单栏文字
PDF 的“文档编辑模式”：先重构为可流动文档，再像文字处理器一样编辑、保存工程和重新导出 PDF。

## 当前功能状态

### 已完成并有自动测试

文档编辑模式：

- 打开 PDF 后在后台提取文字、图片、字体和来源坐标，分析单栏阅读顺序、段落、标题、列表、
  重复页眉页脚及复杂度，并显示 0–100 导入评分和模式推荐。双栏或扫描页会明显降分。
- 文档内容保存在独立、可序列化的 `FlowDocument` 模型中，不把 `QTextDocument` 或原 PDF 固定
  坐标当作唯一数据源；每个导入段落保留来源页、边界框、原文字/字体和置信度。
- 整份文档使用一个连续 `QTextDocument`：可点击放置光标、连续输入中英文、Enter 分段、
  Backspace 合并段落、鼠标/Shift 选择、跨页复制剪切粘贴、撤销重做和中文 IME 提交。
- 内容自动换行并推动后续段落；溢出后页数自动增加，删除后内容向上回流且无硬分页时空白末页
  自动减少。核心 200+ 中文字符增删回流有自动测试。
- 连续文档以分离的白色实体纸张显示，包含真实页边距、页间空隙、阴影和当前页边框；后页点击、
  跨页拖选、双击选词、中文 IME 候选框坐标及滚轮滚动均使用同一页面坐标映射。
- 支持实际大小、适应页面和适应宽度；左侧文档页列表仅为可见页附近生成低分辨率缩略图，
  输入后防抖刷新，避免按键触发整列重绘。
- 支持字体、字号、粗体、斜体、下划线、删除线、文字/背景色、上标/下标、清除格式、四种对齐、
  行距、首行/左右缩进、项目符号、编号、硬分页和普通块级图片。
- `.flowpdfproj` 使用受限 ZIP 容器保存结构、格式、图片及视图状态；检查路径穿越、符号链接、
  压缩炸弹、版本和资产哈希，并用临时文件加原子替换保存。
- 工程保存和 PDF 导出绑定编辑修订号；后台任务运行期间新增的内容仍保持未保存状态，模式切换
  不会丢弃晚到修改。恢复检查点使用会话令牌清理，保存后不会被在途任务重新“复活”。
- 文档模式导出重新排版的新 PDF，不覆盖原页面、也不栅格化整页；导出后会重开验证页数、尺寸、
  文字层、指定中文/英文搜索词和图片数量，验证成功后才替换目标。
- 文档模式自动恢复保存压缩模型与内容寻址图片，不保存 PDF 密码；保存工程后清理对应恢复记录。
- 从文档模式切换到版面模式时先生成并验证固定版式快照；两种模式不伪装成共享同一内部对象。

版面编辑模式：

- 打开、拖放打开、最近文件、新建空白 PDF、中文路径、密码输入。
- 原 PDF 只读使用；首次保存默认建议 `原文件名_已修改.pdf`，禁止静默覆盖原文件。
- 连续滚动和单页模式、虚拟化页面、缩略图、页码跳转、实际大小、适应页面、适应宽度、
  Ctrl+滚轮缩放、混合页面尺寸和横向页面。
- 后台渐进渲染、高倍缩放图块、默认 512 MB 有界 LRU 缓存；缓存上限可设置。排队中的失效
  任务会取消，已经进入 MuPDF 原生调用的任务会丢弃结果，但无法在调用中途强制终止。
- 全文搜索、上一个/下一个结果和页面高亮。
- 页面多选、拖动排序、删除、复制、旋转、插入空白页、插入/合并 PDF、拆分和导出。
- 添加文字（中英文、字体、字号、下划线、文字/背景颜色、透明度、对齐及四种溢出策略）。
- 双击已有文字块并使用真正的内容删除后重写；旧文字不再可搜索或复制。缺失字体会提示替换，
  扫描页会明确提示 OCR 状态。
- 插入 PNG、JPEG、WEBP 图片。
- 高亮、下划线、删除线、便签、直线、箭头、矩形和椭圆批注；批注列表支持跳页、删除和撤销。
- “永久擦除”会删除区域内文字、图片和原矢量内容，不是黑色矩形遮挡。
- 统一命令历史覆盖已接入的编辑及页面操作；支持 Ctrl+Z/Ctrl+Y。
- 临时文件写入、重新打开验证、页数/大小检查和原子替换；保存失败不改坏已有目标。
- 命令恢复日志不保存 PDF 密码；启动时提供“恢复 / 放弃 / 查看详情”。
- 浅色/深色主题、高 DPI 策略、离线测试 PDF 生成器和 Windows 便携目录构建配置。

### 部分完成

- 文档模式第一版重点支持单栏、标题、正文、列表和普通图片。双栏、复杂表格、公式与矢量图会
  降低评分并推荐版面模式；复杂区域的自动图片化降级尚未覆盖所有 PDF 构造方式。
- 图片可插入、删除、按比例调整并左/中/右对齐，工程和 PDF 导出可保留；当前 UI 还没有拖拽
  图片控制点和完整行内/独占一行属性面板。
- 页面设置支持 A4、Letter、自定义尺寸、方向、页边距和基础页码；页眉页脚可以从导入结果保留，
  但尚无完整的可视化页眉页脚编辑器。
- 查找和全部替换可用；搜索栏当前只显示命中总数，不显示文档模式的精确“第 N 个”游标序号。
- 编辑器和 PDF 导出使用不同文字排版引擎；导出会比较两者页数并在不一致时明确提示，切换到
  版面模式前要求再次确认。目前不能保证所有字体组合的逐行分页位置完全一致。
- 页眉、页脚、页码和原始分页策略已有模型选项，但导入对话框尚未暴露完整的保留/移除选项，
  当前使用默认保留页眉页脚、保留页码和连续重排。

- 添加后的文字和图片会正确写入 PDF，但首版界面尚不能再次选择它们进行自由移动、缩放、
  旋转、层级调整或复制粘贴。
- 文字框支持下划线；加粗和斜体控件会明确禁用，等待可靠的字体变体解析，避免输出假效果。
- 已有图片可以被后端识别，但界面尚未提供选中和替换入口。
- 批注可添加、列出和删除；自由手写、橡皮擦、批注属性二次修改及 Windows Ink 优化尚未完成。
- 后台渲染使用 Qt 线程池，但 MuPDF 调用按进程串行保护。PyMuPDF 官方说明其不支持多线程并发，
  后续若需并行渲染应迁移到隔离进程。

### 尚未实现

- 视觉签名库、手写签名画板和证书数字签名。
- 剪贴板图片、对象层的移动/缩放控制点、图片透明度和前后层级。
- OCR 引擎。当前只保留抽象接口、扫描页检测和“可选组件未安装”提示。
- 双栏/多栏的可靠语义重构、复杂表格编辑、公式编辑、完整文字环绕、脚注/尾注、修订协作和
  DOCX 导出。
- 奇偶页不同页眉页脚。
- 复杂表单编辑、书签编辑和证书数字签名。

## 从全新环境启动

开发环境优先使用 Python 3.14，声明兼容范围是 Python 3.12–3.14：

```powershell
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -e ".[dev]"
python -m flowpdf
```

常用命令：

```powershell
scripts\run_dev.ps1
scripts\lint.ps1
scripts\test.ps1
scripts\benchmark.ps1
```

## Windows 构建

正式构建固定为 CPython 3.14.5 x64 和 `requirements-build.txt` 中的精确依赖版本：

```powershell
scripts\build_windows.ps1
```

便携目录输出到 `dist\FlowPDF\`。构建脚本会生成多尺寸 `.ico`，并拒绝使用其他 Python 补丁
版本。详细验证结果见 [BUILD_REPORT.md](BUILD_REPORT.md)。当前产物未代码签名，Windows 可能提示
“未知发布者”。

## 测试与性能

`pytest` 会离线生成普通文字、中文、单栏/双栏、混合尺寸、横向、图片、扫描模拟、300 页、
加密和损坏 PDF，并验证坐标、缓存、撤销、页面操作、文字真替换、安全保存、文档重构、自动
回流、工程格式、恢复及可搜索 PDF 导出。性能脚本输出当前机器的 JSON 基线；这些数字只用于
回归比较，不代表其他电脑的绝对性能。

CI 在 Windows 上测试 Python 3.12 和 3.14，并运行：

```powershell
ruff check .
ruff format --check .
pytest
```

## 文件与安全设计

PDF 被视为不可信输入。FlowPDF 不执行内嵌 JavaScript，不自动打开外部链接或附件；密码只在
内存中保留，日志不记录密码或 PDF 正文。页面、文件大小、页面尺寸、图片大小和渲染像素数均有
安全上限。当前单个源 PDF 上限为 256 MiB、内部对象上限为 25 万；原始文件超过 64 MiB 时
允许查看，但会拒绝快照式编辑并建议先拆分，避免在拒绝前分配多份大型内存对象。保存流程为
“临时文件 → 重新打开验证 → 原子替换目标”，不会在源 PDF 上原地写入。
加密 PDF 的撤销快照和保存副本保持密码保护；页面导出需要所有者密码，并同样通过临时文件、
重新打开验证和原子替换，使用受限用户密码时不会提升权限。

PyMuPDF 明确不支持多线程并发使用，因此所有 MuPDF 原生调用共享进程级重入锁；Qt 后台线程
保证 GUI 不被耗时操作阻塞。若未来需要真正并行处理，将使用独立进程而不是解除该保护。

## 重要限制

- PDF 不是 Word 文档。文档模式通过重构内容实现自由流动，而不是保留每个原坐标；复杂 PDF
  不一定能完全保留原版式，应根据导入评分选择版面模式。
- 原字体缺失时会替换字体，替换结果可能不同；新文字明显更长时需要缩小字号或调整区域。
- 扫描型 PDF 需要 OCR；文档模式已支持普通段落自动重排，但不支持复杂段落、脚注、公式和
  多栏内容的完整自动重构。
- 当前没有具有证书认证能力的数字签名。
- 某些受权限限制、资源异常或损坏的 PDF 无法编辑。
- 超过 64 MiB 的原始 PDF 当前只能查看和拆分，不能进入快照式撤销编辑。
- 快照式撤销设有 256 MB 历史预算；超过预算的单次修改会在执行前拒绝或自动回滚。它对大型
  PDF 的开销仍高，下一阶段应改为增量撤销。
- 普通滚轮保持连续滚动，缩放使用 Ctrl+滚轮；尚未提供“普通滚轮也缩放”的独立设置。
- 右侧属性栏目前只提供基础提示；对象级移动、缩放和二次属性编辑尚未接入。
- 文档模式的真实中文输入法提交和候选框矩形有自动化验证；不同 Windows 输入法及触控设备的
  候选窗口位置仍需按 [MANUAL_DOCUMENT_MODE_TEST.md](MANUAL_DOCUMENT_MODE_TEST.md) 人工核对。
